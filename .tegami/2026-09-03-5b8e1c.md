### Publish npm packages under aliases

`npm.alias` in package options publishes a package under extra names. An alias shares the version, changelog, git tag, and dist-tag of the package:

```ts
tegami({
  packages: {
    "@acme/ui": { npm: { alias: ["acme-ui"] } },
  },
});
```

Each name is published from the package directory with the manifest name swapped for the duration of the publish, so lifecycle scripts rebuild for every name and a build that reads `package.json` sees the alias. Names the registry already has are skipped, so a retry only publishes what is missing. `tegami npm pretrust` configures trusted publishing for aliases too.
